# Orbit

Orbit — компактное нативное приложение строки меню для macOS 14+. Оно показывает
рабочие столы и полноэкранные приложения, выделяет активное пространство и позволяет
настроить цвета, форму, размер, расстояние и стиль переходов.

## Использование

1. Откройте `Orbit.xcodeproj` и запустите схему **Orbit** на **My Mac**.
2. Левый или правый клик по индикаторам открывает меню Orbit.
3. Откройте **«Настройки…»** из меню или сочетанием `Command+,`.
4. Закройте Orbit через пункт **«Завершить Orbit»** или `Command+Q`.

Текущий production-интерфейс использует индикаторы только для отображения: клик по
конкретной точке не переключает Space. Для отображения рабочих столов и анимации
переключений системное разрешение на управление компьютером не требуется.

## Сборка и тесты

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
xcodebuild -project Orbit.xcodeproj -scheme Orbit \
  -configuration Debug -destination 'platform=macOS,arch=arm64' test
```

Deployment target — macOS 14. Release-бинарник собирается для `arm64` и `x86_64`.
Фактическую runtime-совместимость с каждой новой major-версией macOS необходимо
проверять отдельно из-за недокументированного источника данных Spaces.

## Ограничение macOS

Apple предоставляет уведомление об изменении Space, но не публичный API для чтения
полного порядка рабочих столов и полноэкранных приложений. Orbit разрешает private
WindowServer symbols во время выполнения и использует `com.apple.spaces` как
запасной read-only источник. Приложение не зависит от AeroSpace, yabai или сторонних
библиотек. Этот подход не подходит для Mac App Store и может потребовать адаптации
после обновления macOS.
