# Orbit

Orbit — минимальное нативное приложение для строки меню macOS 14+. Оно показывает
обычные Desktop Spaces точками и переключает их стандартным сочетанием macOS
`Control+←/→`.

## Как пользоваться

1. Откройте `Orbit.xcodeproj` и запустите схему **Orbit** на **My Mac**.
2. Нажмите точку, чтобы перейти на соответствующий рабочий стол слева направо.
3. Нажмите правой кнопкой для обновления, явного запроса разрешения или выхода.

Orbit не вызывает запрос Universal Access при нажатии на точку. Если доступ ещё не
выдан, используйте пункт **«Разрешить управление…»** в контекстном меню. macOS также
может один раз запросить разрешение **Automation → System Events**, через которое
отправляется стандартное сочетание `Control+←/→`.
